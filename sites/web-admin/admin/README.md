# StarClub 网站管理工具

星社网站的在线管理后台。

## 功能特点

- **仪表盘**：概览网站数据统计
- **首页横幅**：自定义首页横幅标题、副标题、描述、按钮与核心共创
- **快速入口**：管理首页快速入口链接（支持拖动排序）
- **共创回顾（最新动态）**：管理首页最新动态与星社共创记录
- **成员风采**：管理核心成员信息（支持添加照片链接）与星社成就
- **学习资源**：管理学习资源分类（支持添加链接）
- **推荐书籍**：管理推荐书籍（书名、作者、简介）
- **关于我们**：管理关于我们页面内容
- **指导老师**：管理指导老师信息（姓名、头衔、照片、简介、研究方向）
- **组织架构**：管理组织架构介绍与部门信息
- **联系方式**：更新联系方式
- **招募信息**：管理招募公告
- **星社统计**：更新星社数据统计
- **页脚管理**：自定义页脚三列链接与版权信息、ICP备案、GitHub地址
- **详情页**：创建自定义页面（支持标题、富文本、卡片、图片、视频、音频、内嵌 HTML、Markdown等板块）
- **文件管理**：上传图片、视频、头像等文件
- **账号管理**：管理后台登录账号

## 使用方法

### 1. 启动管理服务器

```bash
# 在 sites/web-admin 目录下运行
python3 admin.py
```

默认端口为 10240，可指定端口：
```bash
python3 admin.py 10240
```

### 2. 访问管理后台

打开浏览器访问：http://localhost:10240/admin/index.html

### 3. 修改网站内容

1. 在左侧导航选择需要管理的模块
2. 点击"添加"按钮可新增内容
3. 点击"编辑"按钮可修改现有内容
4. 点击"删除"按钮可删除内容
5. 修改后点击底部"保存所有更改"按钮

### 4. 导出站点

内容修改并保存后，由 `exporter.py` 将站点数据导出为静态页面（无需手动上传）。

## 新增功能说明

### 首页横幅管理
自定义首页主横幅区域的内容，包括：
- 主标题
- 副标题
- 描述文字
- 两个按钮的文字和链接
- 核心共创（4 个条目：图标、标题、描述、链接）

### 详情页管理
创建可直接引用的自定义页面，支持以下内容板块：
- 二级标题
- 富文本
- 卡片组
- 图片
- 视频
- 音频
- 内嵌 HTML
- Markdown

### 文件上传管理
上传网站所需的各类文件，按分类保存：
- 图片（jpg, jpeg, png, gif, webp, svg, ico）
- 视频（mp4, webm, ogg, avi, mov）
- 头像（jpg, jpeg, png, gif, webp）
- 上传的文件保存在 `uploads/` 目录（按分类存放）
- 可以在资源链接或其他地方引用

### 页脚管理
自定义网站底部页脚信息：
- 三列链接（每列包含列标题与链接项：关于星社 / 快速链接 / 联系我们）
- 版权年份
- ICP备案号
- GitHub地址

### 关于我们管理
管理 about.html 页面内容：
- 页面标题
- 副标题
- 星社简介内容
- 星社宗旨（三个卡片：图标、标题、描述）

### 账号管理
管理后台登录账号：
- 查看账号列表与角色（管理员 / 普通账号）
- 添加账号（用户 ID）
- 删除普通账号（admin 账号不可删除）

## 注意事项

1. **数据安全**：管理工具会直接修改网站源文件，建议操作前备份
2. **离线使用**：网站可以完全脱离管理工具独立运行
3. **导出更新**：修改保存后通过 `exporter.py` 重新导出静态站点
4. **服务器依赖**：管理工具需要 Python 服务器运行
5. **uploads 目录**：上传的文件会保存在 `sites/web-admin/uploads/` 文件夹

- **后端**：Python 3.x (Flask)
- **设计风格**：与主网站保持一致

## 故障排除

### 加载数据失败
- 确保已启动 Python 服务器：`python3 admin.py`
- 检查端口是否被占用：`python3 admin.py 10240`

### 修改未生效
- 点击"保存所有更改"按钮
- 检查浏览器控制台是否有错误
- 确认文件写入权限

### 无法保存
- 检查网站文件是否被其他程序占用
- 确认有写入权限

### 上传文件失败
- 检查 uploads 目录是否有写入权限
- 确保上传文件大小未超过服务器限制
